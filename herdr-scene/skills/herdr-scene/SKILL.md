---
name: herdr-scene
description: "Interpret requests sent from Herdr's scene mods and edit the diagram they refer to. Use for the mermaid mod's Ask messages (quoted lines, On the whole, Group N), and whenever someone wants to view or style a Mermaid diagram shown in Herdr. Not for creating plots, figures or diagrams in general."
---

Run `hscene --skill` and follow it. If `hscene` is missing, point the person to the [README install instructions](https://github.com/mulatta/hmods#install-with-nix).

| Topic | When | Command |
| --- | --- | --- |
| core | Read Ask notes or show a diagram in Herdr | `hscene --skill` |
| mermaid | Find a part, edit source or check the drawing | `hscene --skill mermaid` |
| pele-css | Style a diagram or its file in Herdr | `hscene --skill pele-css` |
